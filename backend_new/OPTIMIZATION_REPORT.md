## Структура эндпоинтов

### Основные эндпоинты
```
GET  /api/v1/films/                    - Список фильмов с пагинацией
GET  /api/v1/films/search              - Поиск фильмов по названию
GET  /api/v1/films/filter              - Фильтрация по жанрам, странам, годам
GET  /api/v1/films/{id}                - Детали фильма
GET  /api/v1/films/kinopoisk/{kp_id}   - Фильм по Кинопоиск ID
GET  /api/v1/films/{id}/similar        - Похожие фильмы
GET  /api/v1/films/{id}/stuff          - Участники фильма
GET  /api/v1/films/{id}/stills         - Кадры и обои
GET  /api/v1/films/{id}/recommendations - Рекомендации
```

### Пользовательские взаимодействия
```
# Закладки
GET    /api/v1/bookmarks/               - Список закладок пользователя
POST   /api/v1/bookmarks/{film_id}      - Добавить в закладки
DELETE /api/v1/bookmarks/{film_id}      - Удалить из закладок
GET    /api/v1/bookmarks/{film_id}/status - Статус закладки

# Комментарии
GET  /api/v1/comments/{film_id}         - Комментарии к фильму
POST /api/v1/comments/{film_id}         - Добавить комментарий
PUT  /api/v1/comments/{comment_id}      - Редактировать комментарий
DELETE /api/v1/comments/{comment_id}    - Удалить комментарий

# Рейтинги
GET  /api/v1/ratings/films/{film_id}/rating - Рейтинг пользователя
POST /api/v1/ratings/films/{film_id}/rating - Установить рейтинг
PUT  /api/v1/ratings/films/{film_id}/rating - Изменить рейтинг
DELETE /api/v1/ratings/films/{film_id}/rating - Удалить рейтинг
GET  /api/v1/ratings/films/{film_id}/average - Средний рейтинг фильма

# История просмотров
POST /api/v1/history/films/{film_id}/visit - Добавить в историю
GET  /api/v1/history/films                - История пользователя
DELETE /api/v1/history/films             - Очистить историю
GET  /api/v1/history/films/stats         - Статистика истории
```

### Аутентификация
```
POST /api/v1/auth/login                  - Вход
POST /api/v1/auth/register               - Регистрация
POST /api/v1/auth/verify                 - Подтверждение email
POST /api/v1/auth/reset-password         - Сброс пароля
```

### Админ эндпоинты
```
# Фильмы (только для суперпользователей)
GET    /api/v1/admin/films/              - Список всех фильмов
POST   /api/v1/admin/films/              - Создать фильм
GET    /api/v1/admin/films/{id}          - Детали фильма
PUT    /api/v1/admin/films/{id}          - Обновить фильм
DELETE /api/v1/admin/films/{id}          - Удалить фильм

# Участники (только для суперпользователей)
GET    /api/v1/admin/stuff/              - Список всех участников
POST   /api/v1/admin/stuff/              - Создать участника
GET    /api/v1/admin/stuff/{id}          - Детали участника
PUT    /api/v1/admin/stuff/{id}          - Обновить участника
DELETE /api/v1/admin/stuff/{id}          - Удалить участника
```
