# Film Base Frontend - Полная документация

## 🎯 Описание проекта

Современное React/Next.js приложение для управления личной коллекцией фильмов с интеграцией к backend_new API.

## 🏗️ Архитектура

### Технологический стек:
- **Next.js 14** с App Router
- **TypeScript** для строгой типизации
- **Zustand** для state management
- **Axios** для HTTP запросов
- **React Query** для кеширования данных
- **TailwindCSS + shadcn/ui** для стилизации
- **Framer Motion** для анимаций

## 🔧 Конфигурация

### Переменные окружения:
```env
NEXT_PUBLIC_API_URL=http://localhost:8000/api/v1
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### API Endpoints (backend_new):

**Аутентификация:**
- `POST /auth/login` - вход
- `POST /auth/register` - регистрация
- `POST /auth/logout` - выход
- `GET /users/me` - профиль пользователя

**Фильмы:**
- `GET /films/` - список фильмов с пагинацией
- `GET /films/search` - поиск по названию
- `GET /films/filter` - фильтрация (жанры, страны, годы, рейтинги)
- `GET /films/{id}` - детали фильма
- `GET /films/{id}/recommendations` - рекомендации

**Пользовательские взаимодействия:**
- `GET /bookmarks/` - список закладок
- `POST /bookmarks/{film_id}` - добавить в закладки
- `DELETE /bookmarks/{film_id}` - удалить из закладок
- `GET /ratings/films/{film_id}/rating` - рейтинг пользователя
- `POST /ratings/films/{film_id}/rating` - поставить рейтинг
- `GET /comments/{film_id}` - комментарии к фильму
- `POST /comments/{film_id}` - добавить комментарий
